## exchange-intro

An introduction to how exchanges work for people with no financial background.
Choose the format that suits you best. If you have accesst´to an ebook reader we
recomment the **EPUB** rendering as that gives you freedom to choose font size and
background color.

The latest version is a pre-release of the second edition that is awaiting editor
revview so expect errors, typos, or other problem. 

### EPUB rendering

1. [EPUB](exchange_intro/exchange_intro-1.10.1.epub)

### B5 PDF Rendering

B5 is a common book format. It ie better suitable if you intend reading the PDF on a 
tablet since a A4 format will be more heavier scaled on a smaller tabblet.

1. [PDF B5 Light background](exchange_intro/exchange_intro_b5-1.10.1.pdf)
2. [PDF B5 Dark background](exchange_intro/exchange_intro_dark_b5-1.10.1.pdf)

### A4 PDF Rendering

A4 (light background) is the best format if you intend to print the book on a regular
office printer.

1. [PDF A4 Light background](exchange_intro/exchange_intro_a4-1.10.1.pdf)
2. [PDF A4 Light background](exchange_intro/exchange_intro_a4-1.10.1.pdf)
